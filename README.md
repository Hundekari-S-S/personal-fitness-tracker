🏃 Personal Fitness Tracker Using Python
A Python-based Personal Fitness Tracker designed to help users monitor their daily physical activities, record exercises, set fitness goals and track their progress.

📌 Project Overview
Maintaining a healthy lifestyle requires regular monitoring of physical activities and fitness goals. This project provides a simple and cost-effective fitness tracking system using Python.
Users can log their exercises, specify exercise duration and intensity, set fitness targets and monitor their progress through a simple menu-driven interface.

✨ Features

Exercise Logging: Record activities such as walking, running, cycling, and gym exercises.

Duration Tracking: Enter and monitor exercise duration in minutes.

Intensity Tracking: Record exercise intensity on a scale of 1–10.

Goal Setting: Set personalized fitness goals, such as calorie targets.

Progress Monitoring: Calculate and display progress toward fitness goals in percentage.

User-Friendly Interface: Simple, interactive, menu-driven Python application.

🛠️ Technologies Used

Python,
NumPy,
Pandas,
IDLE / Python IDE

⚙️ How It Works

The application provides four main options:

Log Exercise: Enter exercise name, duration, and intensity.

Set Goal: Select a fitness goal type and enter the target value.

Track Progress: View the percentage of goal completion.

Exit: Exit the application after completing the tracking session.
